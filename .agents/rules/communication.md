# Reglas de Comunicación y Feedback Continuo

1. **Entendimiento Inicial:** Al recibir cada instrucción, desglosar brevemente qué se comprendió del pedido para que el usuario valide la dirección.
2. **Razonamiento y Decisiones Explícitas:** Explicar el porqué de cada decisión técnica, arquitectónica o de interfaz antes y durante la ejecución.
3. **Reporte de Acciones en Tiempo Real:** Detallar con precisión qué archivos se van a editar, qué comandos se ejecutarán y qué resultados se obtuvieron.
4. **Dudas y Alternativas:** Plantear de inmediato cualquier ambigüedad, trade-off o duda que surja durante el proceso.
